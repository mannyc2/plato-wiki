# v2.0.0 — Public knowledge-base candidate

v2.0.0 is the first release candidate for the complete guided knowledge-base
edition. It supersedes the private historical v1.0 corpus milestone without
claiming completion of the separate audio edition.

## Included

- 27 canonical Greek and English reading spines;
- complete, reviewed observation, claim, relation, and reported-turn layers;
- 27 accepted guided-reading ledgers and 27 current commentary quality audits;
- deterministic derived indexes, comparison artifacts, and validated static
  site source;
- exact source, review, export, and licensing receipts required by the public
  release gate.

## Excluded

- audio recordings and production media;
- private plans, scratch, transcripts, provider credentials, and private
  release sidecars;
- quarantined legacy translation conversions.
