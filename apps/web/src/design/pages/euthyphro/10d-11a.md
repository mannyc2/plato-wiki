## What’s happening {#happening}

Socrates now turns the point on the holy, and Euthyphro answers each question.

:::moves
1. The holy is loved by all the gods, as Euthyphro said.[^all]
2. They love it because it is holy, not for some other reason.[^reason]
3. So it is loved because it is holy, not holy because it is loved.[^holyfirst] To this Euthyphro says, “I think so.”[^think]
4. But what is dear to the gods is dear to them because they love it.[^dear]
5. So what is dear to the gods and what is holy are not the same, but differ.[^differ]
6. If they were the same, then just as what is dear to the gods is dear because it is loved, the holy would be holy because it is loved; but the opposite is the case.[^opposite]
:::

What is dear to the gods, Socrates sums up, is lovable because it is loved;[^lovable] the holy is loved because it is lovable.[^loved] So it seems, he says, that Euthyphro, asked what holiness is, was unwilling to make plain its essence,[^essence] and named instead something that has happened to it: that it is loved by all the gods.[^happened]
