# Security Policy

## Supported release

Security reports are accepted for the current public source release. The
project does not provide security support for private historical snapshots,
generated scratch artifacts, or model-provider credentials.

## Reporting

Use GitHub's private security-advisory flow for the repository. Do not include
API keys, private transcripts, source credentials, or other secrets in a
public issue.

The public export deliberately excludes `.env` files, transcripts, scratch
directories, private release receipts, and production media. A report that any
of these appear in a release artifact should be treated as high priority.
